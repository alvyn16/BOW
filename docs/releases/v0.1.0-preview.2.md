# BOW 0.1.0-preview.2

- Includes Microsoft's signed WebView2 Evergreen setup program in the ZIP.
- Adds **Install WebView2** to the missing-runtime screen. BOW checks the installer's
  trusted signature and Microsoft publisher, installs the runtime, and retries
  the page. Internet access is required for initial runtime setup.
- Reuses existing Evergreen installations and Microsoft's runtime update mechanism.
- Adds Windows tests that reject unsigned and modified installer files.
- Adds certificate validation, SHA-256 Authenticode signing, timestamping, and
  signature verification to the local release build scripts.

BOW itself remains unsigned because no trusted publisher certificate is configured.
The Microsoft signature applies only to the bundled WebView2 installer.
See [installation instructions](https://github.com/alvyn16/BOW/blob/main/docs/INSTALL.md)
and [signing setup](https://github.com/alvyn16/BOW/blob/main/docs/SIGNING.md).

Extract the full ZIP before running BOW. The archive includes .NET and Windows
App SDK dependencies, a release manifest, and third-party notices. Download the
adjacent SHA-256 file to verify the archive.
