# BOW 0.1.0-preview.1

First portable preview release for Windows x64.

- Tab dragging, animated reordering, and split-view previews.
- Split-view exit keeps both tabs; Ctrl+W closes the focused pane's tab.
- Tab sleep controls and site exceptions to reduce background memory use.
- Tracking prevention and browsing-data clearing in Settings.
- Back, Forward, and Reload controls, plus customizable keyboard shortcuts.
- Ctrl+Y maximizes or restores the window; page video fullscreen hides browser chrome.
- URL credential filtering before JSON persistence and debounced session saves.
- Windows CI builds, runs unit tests, and checks WinUI/WebView2 startup from the extracted ZIP.

Download the ZIP and its SHA-256 file, then follow
[installation instructions](https://github.com/alvyn16/BOW/blob/main/docs/INSTALL.md).
Extract the entire archive before running `BOW.exe`.

The ZIP includes .NET and Windows App SDK dependencies. WebView2 Evergreen
Runtime is required separately. This preview is unsigned and has no automatic
updater. URL filtering is best-effort; clearing browsing data does not clear
saved passwords, autofill, or the current session. See the README for details.
