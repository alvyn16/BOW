# Security policy

BOW is preview software, not a security-audited browser. Security fixes target
the current `main` branch and the newest preview; older previews do not have
a separate maintenance commitment. Use an up-to-date WebView2 Evergreen Runtime.

## Report privately

Use [GitHub's private vulnerability reporting](https://github.com/alvyn16/BOW/security/advisories/new).
If private reporting is unavailable, do not post exploit details, credentials,
or browsing data in a public issue. Open a minimal issue asking the maintainer
to enable a private reporting channel before sharing sensitive details.

Include the affected version, Windows and WebView2 versions, reproducible steps,
expected versus actual behavior, and the privacy/security impact. Use synthetic
accounts and data. Never send signing private keys or passwords.

The project does not currently guarantee a response time. Please allow the
maintainer to investigate and coordinate a fix before public disclosure.
